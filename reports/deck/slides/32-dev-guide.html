Developer Guide: Extension Patterns

Custom Tool

  • Subclass Tool(ABC) in tools/my_tool.py
  • Implement call(), is_read_only(), is_concurrency_safe(), is_enabled()
  • Define name, description, input_schema properties
  • Call register_builtin_tools([MyTool()]) in cli.py bootstrap
  • Tool name and schema auto-appear in system prompt

Custom Skill

  • Create ~/.easy-agent/skills/my-skill.md
  • YAML frontmatter: name + description minimum
  • Optionally: allowedTools, budget, paths
  • No code change — auto-discovered at startup

Custom Agent

  • Create ~/.easy-agent/agents/my-agent.json
  • Set agent_type, description, system_prompt, tools_allow, isolation
  • Optionally: model for a different Claude tier
  • Reference via agent_type in AgentTool calls

MCP Server

  • Add entry to mcpServers in ~/.easy-agent/settings.json
  • Specify command, args, transport
  • Optionally: env for API keys/credentials
  • Restart — tools appear as mcp__<server>__<tool>
Extension priority: Skill (zero code) → Tool (Python logic) → Agent (scoped delegation) → MCP (external integration)
