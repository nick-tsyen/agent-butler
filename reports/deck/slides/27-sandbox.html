Platform Services

Sandbox: macOS sandbox-exec

Processing pipeline

Bash tool call
↓
sandbox/should_use.py — gate: sandboxable?
↓
sandbox/split_command.py — split && / || compounds
↓
sandbox/build_profile.py — compose SBPL profile
↓
sandbox/wrap.py — compile + wrap

Wrapped command

/usr/bin/sandbox-exec \ -p '<compiled-profile>' \ /bin/bash -lc '<command>'

SBPL profile example

(version 1) (deny default) (allow process-exec) (allow file-read* (subpath "/workspace")) (allow file-write* (subpath "/workspace")) (deny file-write* (subpath "/workspace/.git")) (deny network-outbound)

Platform availability

  • macOS — auto-enabled (kernel-level enforcement via sandbox-exec)
  • Linux / Windows — graceful no-op (sandbox layer bypassed)
  • Detection: sandbox/availability.py
Violation monitoring: sandbox/violations.py monitors stderr for policy violations and surfaces them as warnings.
