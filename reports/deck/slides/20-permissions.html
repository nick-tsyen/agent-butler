Permission System

Three modes

Mode Behaviour
default Read-only tools auto-allowed; writes/shell require confirmation
plan Only Read, Grep, Glob (and read-only Bash) — mutations hard-blocked
auto All operations auto-approved (for CI/scripting)

Rule syntax

{ "permissions": { "allow": [ "Read", "Bash(npm test *)", "mcp__filesystem*" ], "deny": ["Bash(rm -rf *)"] } }

Permission decision flow

  1. Match against deny rules → deny if matched
  2. Match against allow rules → allow if matched
  3. If mode == "auto" → allow
  4. If mode == "plan" and not read-only → deny
  5. Otherwise → prompt user: allow_once | allow_always | deny
Load hierarchy: user scope (~/.easy-agent/settings.json) → project scope (./.easy-agent/settings.json) → session rules (allow_always decisions)
