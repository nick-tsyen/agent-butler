Terminal UI

Event flow

User input
↓
App._handle_submit() ui/app.py
↓
SessionController.submit() ui/session_hook.py emits UIEvents
↓
App._process_event() ui/app.py
↓
TUILayout.add_event() ui/layout.py
↓
Rich Live.refresh() ~30ms throttle via StreamingBuffer

UIEvent types

EventPurpose
UISpinnerStartShow thinking indicator
UITextDeltaStream text to conversation view
UIToolStartShow tool card with input
UIToolDoneUpdate tool card with output
UIPermissionRequestShow inline approval prompt
UITurnCompleteFinalise turn, show usage stats
UIErrorDisplay error banner

TUILayout components

  • ConversationView — markdown-rendered message history
  • ToolCard — live tool invocation with collapsible input/output
  • TodoListView, TaskListView — checklist and persistent tasks
  • StatusBar — model, permission mode, token usage
  • Spinner — breathing-star + shimmer animation
