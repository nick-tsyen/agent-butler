Test modules

ModuleWhat it covers
test_tools.py Tool registry operations; get_all_tools(), find_tool_by_name(); execution contracts; read-only and concurrency-safe flags
test_streaming.py StreamEvent accumulation; partial JSON assembly for tool_use blocks; SSE parsing edge cases
test_tasks.py Task and TaskStatus Pydantic model serialisation; field validation; status transitions
test_permissions.py Rule matching (exact, wildcard, parameterised); mode transitions; plan-mode hard-block behaviour
test_sandbox.py SBPL profile compilation; compound command splitting (&&/||); should_use gate logic

How to run

# Activate virtual environment source .venv/bin/activate # Full suite pytest tests/ -v # Single module pytest tests/test_permissions.py -v
Shared fixtures in tests/conftest.py: mock ToolContext, temp dirs, fake API responses.
Tests are offline, unit-level only. Integration tests (live Anthropic API, MCP connections) are not included — they require live credentials and are left to the user.
