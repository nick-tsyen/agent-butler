Skills System

Skill markdown example

--- name: review description: Perform a thorough code review allowedTools: [Read, Grep, Glob] budget: 3000 paths: [src/*, tests/*] --- You are an expert code reviewer. Focus on correctness, security, and maintainability. Be specific about file locations and line numbers.

Frontmatter fields

Field Required Purpose
name Yes Invocation name
description Yes Shown in system prompt so Claude knows when to use it
allowedTools No Restrict tool access for this skill
budget No Max tokens for skill context
paths No Conditional activation path patterns

Activation modes

Dynamic (no paths) — always in system prompt, globally available
Conditional (has paths) — activated only when CWD matches a path pattern
Load order: ~/.easy-agent/skills/ (user) → ./.easy-agent/skills/ (project)
Project scope overrides user scope on name collision.
