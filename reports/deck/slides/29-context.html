Auto-compaction flow

  1. Monitor token usage per turn via utils/tokens.py
  2. 80% of context window → warn user: “Context getting long”
  3. 95% of context window → trigger context/compaction.py
  4. Claude summarises conversation → summary replaces history + last N turns
  5. Session continues normally with compact context
