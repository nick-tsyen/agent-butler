MCP: Model Context Protocol

MCP is an open standard for exposing tool APIs to LLMs. Easy Agent implements the client side.

Configuration example

{ "mcpServers": { "filesystem": { "command": "npx", "args": ["@modelcontextprotocol/server-filesystem"], "transport": "stdio" }, "github": { "command": "npx", "args": ["@modelcontextprotocol/server-github"], "transport": "stdio", "env": { "GITHUB_TOKEN": "..." } } } }

Bootstrap flow

  1. Parse configs from settings.json
  2. Connect with 30-second timeout (stdio / http / SSE)
  3. Call list_tools() — discover names, descriptions, schemas
  4. Wrap each as native Tool object
  5. Name: mcp__<server>__<tool> (e.g. mcp__filesystem__read_file)
  6. Register in _mcp_tools global

Key files

services/mcp/client.py Connection caching by config signature
services/mcp/fetch_tools.py Schema normalisation; wraps MCP tools as native Tool objects
services/mcp/normalization.py Adapts MCP JSON Schema to internal form

Transports & naming

3 transports supported: stdio, http, sse.
Tool naming uses mcp__ prefix to prevent namespace collisions with built-ins.
