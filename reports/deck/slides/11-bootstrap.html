Entry Point & Core Loop

Bootstrap Sequence

  1. load_env() Loads .env, ~/.claude.json, and ~/.claude/settings.json into process environment utils/load_env.py
  2. bootstrap_skills() Scans ~/.easy-agent/skills/*.md and ./.easy-agent/skills/*.md; parses YAML frontmatter; builds skill registry
  3. bootstrap_mcp() Reads mcpServers from settings.json; connects servers; calls list_tools(); wraps as native Tool objects
  4. register_builtin_tools([...]) Registers all 16 built-in tools in the _builtin_tools list
  5. Mode branch:
    Interactive → create App → app.run() starts async REPL Print → create SessionController → submit(msg) → print → exit
  6. Teardown — disconnect_all() closes all MCP server connections

Why order matters

The system prompt is assembled at turn-time from the registered tools and skills. Any tool or skill registered after system-prompt assembly would be invisible to Claude.

Tools registered → visible to Claude
Tools added late → invisible

Skills loaded → injected into prompt
Skills added late → not injected
