Introduction

What Is Easy Agent?

  • Interactive multi-turn REPL Chat with Claude while it reads and edits your codebase in real time
  • Tool execution File read/write, shell commands, code search — all sandboxed with explicit permission gates
  • Sub-agent delegation Spawn isolated agents for scoped tasks; results fed back to the parent session
  • MCP integration Connect external tool servers via Model Context Protocol; auto-discovered at startup
  • Skills system Reusable Markdown-defined workflows injected into the system prompt
  • Permission system Three modes: default (confirm), plan (read-only), auto (fully approved)
  • Persistent state Sessions, tasks, memory — all file-backed under ~/.easy-agent/
