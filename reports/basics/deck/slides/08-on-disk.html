On-Disk State Layout

~/.easy-agent/ ├── settings.json ├── AGENT.md ├── tasks/ │ └── <list_id>/ │ └── <task_id>.json ├── plans/ ├── projects/ │ └── <encoded_cwd>/ │ ├── sessions/ │ │ └── <id>.jsonl │ ├── memory/ │ │ └── *.md │ └── tasks/ │ └── *_output.txt ├── skills/ │ └── *.md ├── agents/ │ └── *.json └── worktrees/ └── <name>/
settings.json Permissions, MCP server definitions, sandbox config, model override
projects/<cwd>/sessions/ JSONL conversation history — one file per session Resumable with --resume <id>; all turns preserved
projects/<cwd>/memory/ Persistent Markdown memories scoped to this project Injected into system prompt on every session start
skills/*.md User-scope skill definitions with YAML frontmatter Merged with project-scope skills at ./.easy-agent/skills/
worktrees/<name>/ Isolated git worktrees for sub-agent file operations Created and cleaned up automatically by the delegation tool
Project-scope override: place a .easy-agent/ directory next to your codebase to override skills, agents, or settings without affecting global config.
