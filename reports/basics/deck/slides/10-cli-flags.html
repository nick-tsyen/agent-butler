CLI Flags & Entry Point

easy-agent (CLI) → easy_agent/cli.py : main() → asyncio.run(_async_main(args))
Flag Effect
--model claude-opus-4 Override the Claude model for this session
--plan Read-only mode — only Read/Grep/Glob/Bash-read allowed
--auto All operations auto-approved; no confirmation prompts
--resume SESSION_ID Resume a previous conversation from its JSONL file
--cwd /path/to/project Change working directory before session starts
--print "question" Non-interactive; print response to stdout and exit

Interactive mode

Rich TUI REPL with streaming text and live tool cards. Default when no --print flag given.

$ easy-agent

Print mode

Stdout only; no TUI. Combine with --auto for CI and scripting pipelines.

$ easy-agent --print "..." --auto

CI-friendly invocation

easy-agent --print "Summarise recent changes" \ --auto --cwd /path/to/repo
