agents/types.py — AgentDefinition

# agents/types.py @dataclass class AgentDefinition: agent_type: str # e.g. "explore" description: str # shown to parent Claude system_prompt: str model: str | None # optional override tools_allow: list[str] = field(default_factory=list) tools_deny: list[str] = field(default_factory=list) isolation: str = "none" # "none" | "worktree" max_turns: int = 100

Execution modes

ModeBehaviourReturns
Foreground Blocks until complete Result inline
Background Returns immediately agent_id; completion queued as notification

Isolation options

  • "none" — shares main working directory (suitable for read-only tasks)
  • "worktree" — creates isolated git worktree (utils/worktree.py); agent's file mutations are fully isolated; auto-removed if unchanged

Built-in agents

explore — Read, Grep, Glob only — safe read-only exploration
general_purpose — full tool access

Custom agents: JSON files in ~/.easy-agent/agents/ or ./.easy-agent/agents/
