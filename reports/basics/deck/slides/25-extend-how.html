How to Extend Easy Agent

Add a Custom Tool

# 1. Subclass Tool in tools/my_tool.py class MyTool(Tool): async def call(self, input, ctx): return ToolResult(output="done") def is_read_only(self): return False def is_concurrency_safe(self): return False # 2. Register at bootstrap (cli.py) register_builtin_tools([MyTool()])

Add a Skill

  • Create ~/.easy-agent/skills/my-skill.md
  • Add YAML frontmatter: name, description, optionally allowedTools, budget, paths
  • No code change needed — auto-discovered at startup via services/skills/load_skills_dir.py

Add a Custom Agent

  • Create ~/.easy-agent/agents/my-agent.json
  • Populate AgentDefinition fields: agent_type, system_prompt, tools_allow, isolation
  • Reference via agent_type in AgentTool calls

Connect an MCP Server

// ~/.easy-agent/settings.json { "mcpServers": { "my-server": { "command": "npx", "args": ["@my/mcp-server"], "transport": "stdio" } } }

Restart → tools appear as mcp__my-server__*

Start with a skill (zero code). Escalate to a tool when you need Python logic. Use MCP for external integrations.
