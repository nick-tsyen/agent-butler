Introduction

Use Cases

01

Interactive Dev Assistance

Run easy-agent in any repository. Claude reads your files, runs tests, and edits code in real time as you converse. Ideal for onboarding a new codebase, tracking down bugs, or driving a refactor without context-switching out of the terminal.

Launch

easy-agent

02

Automated Task Pipelines

Use --print to get a single response on stdout and exit. Combine with --auto to skip all confirmation prompts. Point at any directory with --cwd. Compose with shell scripts, CI steps, or cron jobs without any code changes.

CI-friendly

easy-agent --print "Summarise changes" \ --auto --cwd /path/to/repo

03

Extensible Platform

Drop in custom tools by subclassing Tool, add skills as plain .md files, define new agents with a JSON file, or connect MCP servers by editing settings.json. Zero core code changes required for any of these extension points.

Custom skill

~/.easy-agent/skills/my-skill.md ./.easy-agent/skills/local-skill.md
