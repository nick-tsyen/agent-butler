Tool Batching: Concurrent vs Sequential

Concurrent (safe) asyncio.gather()

Runs all tools in the batch simultaneously via asyncio.gather().

Read Grep Glob Agent

is_concurrency_safe() returns True

Sequential (unsafe) await one-at-a-time

Runs each tool with await, one after the other — preserves ordering.

Write Edit Bash Skill TodoWrite TaskCreate TaskUpdate TaskGet TaskList EnterPlanMode ExitPlanMode MemoryWrite

is_concurrency_safe() returns False (default)

Example scenario

Claude's turn calls: [Read(a.py), Read(b.py), Read(c.py), Write(d.py)] Concurrent batch: [Read(a.py), Read(b.py), Read(c.py)] — parallel Sequential batch: [Write(d.py)] — after concurrent done
Reading 10 files takes the time of reading 1 file. The batching logic lives in core/agentic_loop.py.
