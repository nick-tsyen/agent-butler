Turn limit

Max 100 turns prevents infinite loops. The loop itself is a simple while-loop; the complexity lives in batching and permissions.

Tool batching: concurrency-safe tools (read-only, no side effects) run in parallel via asyncio.gather(). Unsafe tools (writes, shell) run serially to preserve determinism.
