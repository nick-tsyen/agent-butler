Concept

Initialization Phase

  • Initialization and implementation have conflicting optimization targets — never mix them.
  • A mixed first session produces fragile infra (20% effort) and unverified feature code (80% effort).
  • Subsequent sessions inherit a broken loop: no known run command, no verified test runner, no state record.
  • Initialization is a distinct phase with its own completion criteria, not just the first hour of sprint 1.
