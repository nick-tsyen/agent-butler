Entry File Design

  • Keep the entry file to 50–200 lines — a map, not a manual.
  • Reveal on demand: route to module docs via short links, not inline walls of text.
  • Critical rules belong at the very top or very bottom — the middle is a statistical dead zone.
  • Every rule needs an owner, a trigger condition, and an expiry condition to fight instruction debt.
