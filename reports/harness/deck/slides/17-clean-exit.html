Clean Exit Checklist

  • Session completion requires a clean state, not just working code.
  • Five dimensions gate handoff readiness across build, tests, and docs.
  • Any miss means fix or roll back before the next session starts.
⚠️ End-of-session entropy drives drift. Agents copy the mess they inherit.
Exit Checklist (5 Dimensions)
BuildRun the full build pipeline.
TestsExecute the complete test suite.
ProgressUpdate feature list and handoff artifacts.
HygieneRemove debug logs, TODOs, and temp files.
StartupVerify the standard dev start path.
