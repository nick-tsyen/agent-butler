Termination discipline

Prevent Premature Victory

  • Externalize the definition of done into executable checks.
  • Use a three-layer gate: static analysis → runtime verification → system-level confirmation.
  • Separate worker and checker so completion is harness‑verified, not self‑reported.

⚠️ Overconfidence is systematic. Modern models report higher confidence than their actual accuracy, so the harness must override subjective “done.”
