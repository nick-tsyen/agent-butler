Task Boundaries & WIP=1

  • Overreach: agent activates more tasks than it can finish — caused by vague scope, not model capability.
  • Under-finish: code written, tests not passing — completion without evidence.
  • WIP=1 must be enforced by the harness, not left to the agent's self-regulation.
  • Every task requires executable completion evidence — "the code looks fine" is not done.
